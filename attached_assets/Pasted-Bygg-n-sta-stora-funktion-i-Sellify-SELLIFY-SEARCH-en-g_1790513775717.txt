Bygg nästa stora funktion i Sellify:

SELLIFY SEARCH – en global annonsaggregator för begagnade produkter, fordon och andra marknadsplatser.

Grundidén är ungefär:

"Booli för allt"

Sellify ska kunna samla annonser från många externa källor, normalisera informationen och göra allt sökbart i ett gemensamt gränssnitt.

VIKTIG PRINCIP

Vi ska INTE bygga ett system som olovligen kopierar andra marknadsplatsers innehåll.

Källor ska delas upp i fyra typer:

1. OFFICIELLT API
2. PARTNER-/FEED-INTEGRATION
3. TILLÅTEN INDEXERING AV ORIGINALKÄLLOR
4. EJ TILLÅTEN / KRÄVER AVTAL

Systemet måste respektera respektive sajts användarvillkor, robots-regler, API-villkor, copyright och rate limits.

Använd aldrig:
- inloggningsbypass
- CAPTCHA-bypass
- proxyrotation för att kringgå blockering
- automatiserad scraping av sajter som förbjuder det
- privata API:er
- reverse engineering av autentisering
- automatiserad kopiering av hela annonser om vi saknar rättighet

Om en källa förbjuder scraping ska adaptern markeras som:
REQUIRES_PARTNERSHIP

och inte aktiveras automatiskt.

==================================================
1. ÖVERGRIPANDE ARKITEKTUR
==================================================

Bygg Sellify Search som ett adaptersystem.

Varje extern källa ska ha en egen adapter.

Exempel:

sources/
  tradera/
  ebay/
  blocket/
  wayke/
  craigslist/
  cars/
  autotrader/
  zillow/
  redfin/
  realtor/
  mls/
  brokers/
  dealers/
  auctions/

Varje adapter ska implementera samma interface:

- sourceId
- sourceName
- country
- sourceType
- enabled
- requiresApiKey
- requiresPartnership
- fetchListings()
- fetchListing()
- normalizeListing()
- refreshListing()
- markUnavailable()
- getOriginalUrl()

sourceType ska vara:

API
FEED
INDEX
PARTNERSHIP_REQUIRED
DISABLED

4. GENERISK INDEXERINGSMOTOR
==================================================

Bygg en generisk indexeringsmotor för sajter där indexering uttryckligen är tillåten.

Prioritetsordning:

1. API
2. JSON feed
3. XML feed
4. RSS
5. Sitemap
6. Schema.org JSON-LD
7. Publik HTML

HTML ska vara sista alternativet.

Före HTML-indexering:

- kontrollera source configuration
- kontrollera robots.txt
- kontrollera admin-status
- kontrollera rate limit
- kontrollera att sourceType = INDEX
- kontrollera att legalApproval = true

Ingen källa får börja crawlas bara för att URL:en fungerar.

==================================================
8. SELLIFY-SÖKNING
==================================================

På startsidan ska användaren kunna söka över:

- Sellifys egna annonser
- externa annonser

Visa gemensamt resultat.

Exempel:

"iPhone 16 Pro"

Resultat:

Sellify
Tradera
eBay
Bilhandlare
Secondhandbutik

Varje extern annons ska tydligt visa källa:

"Via Tradera"
"Via eBay"

och knapp:

"Visa originalannons"

==================================================
9. DEDUPLICERING
==================================================

Samma produkt kan finnas på flera sajter.

Bygg deduplicering baserat på:

- titel
- brand
- model
- pris
- bilder/image hashes när tillåtet
- seller
- location
- GTIN/EAN/ISBN/VIN
- timestamps

Skapa möjlighet att gruppera:

"Samma produkt finns på 3 marknadsplatser"

Visa då:

Tradera 8 900 kr
eBay 8 700 kr
Sellify 8 500 kr
